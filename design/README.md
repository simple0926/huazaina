# 花在哪 · UI 方向 02「私人月结单」

> 方向 02「月结单」已落地到应用 v1.2（松墨配色 + 收入，`android/release/花在哪-v1.2.0.apk`）。本目录保留设计稿与规范；`app.css` / `app.js` 是实现版。

## 一句话

不把账本做成可爱的记账卡片，而做成**一份只给一个人看的月结单**：冷静的纸、精确的线、克制的朱红，金额和分类像报表一样对齐，让「钱花在哪」成为一页可以读的文件。

## 为什么是这个方向

- 产品的核心不是「记账游戏」，是**数据所有权 + 看懂花销**。报表语言比卡片语言更接近这件事。
- 现有版本偏软：圆角卡片、彩色圆形图标、较多强调色。月结单版用**线、编号、对齐**替代卡片，让信息自己形成层级。
- 记账页仍然保留 5×2 分类和自绘键盘，速度不牺牲；变化在「看起来像一份文件」，而不是「多一个装饰」。

## 视觉系统

**色彩**：纸 `#F6F4ED`、墨 `#17160F`、次级墨 `#555044`、弱化 `#7E7767`、印章红 `#7C2B23`。分类色只在报告和图标里出现，压低饱和：居住橄榄 `#56603A`、学习墨绿 `#2F5F5A`、人情赭 `#8A6428`、购物酒红 `#8E3F4E`、娱乐紫 `#5E4A78`。

**字体**：宋体（Songti SC / Source Han Serif）只给金额、日期、封面标题；正文/表格用 PingFang；行号、索引、英文小标用等宽（SF Mono）。金额一律 `tabular-nums`，右对齐。

**尺度**：390 × 844；18px 页边；8px 基线；发丝线 1px `rgba(23,22,15,.16)`；主规则 2px 墨；印章红方块 10px。

**规则**：
1. 线代替卡片：没有圆角卡片、没有阴影、没有彩色底板；分区用 1px / 2px 横线。
2. 编号代替图标：明细行有 01–72 的行号；分类表有 01–06；设置分组有英文小标。
3. 黑代替圆角：选中态是整块墨，不是描边胶囊。
4. 点线引导：明细行名与金额之间用 1px 点线，像印刷账页。
5. 一个强调色：朱红只给印章、支出上涨、危险操作和提示线。

**动效规格（若实现）**：

| 动作 | 方式 | 时长 |
| --- | --- | --- |
| 按键 | 背景墨色从下往上填，缩放 0.98 | 120ms |
| 记下这笔 | 按钮压到 0.985 再回弹，金额数字滚动到合计 | 220ms / 380ms |
| 翻月 / 切报告 | 报表内容整体位移 12px + 淡入，方向跟随前后 | 260ms |
| 柱状图 | 从基线向上长，错峰 18ms | 420ms |
| 弹层 | 从底部滑入，scrim 淡入 | 320ms |

## 关键取舍

- **月报用一条折线看每日**：如果按日画 31 根柱，一笔 3,200 的房租会把其余 30 天压成 1–6px；改成一条 31 点的细折线 + 最高点朱红圆点，既保留每日粒度，也不制造「3 天 vs 7 天」的不等长周柱。
- **报告不用环形图**：分类用「编号 + 细条 + 行末金额」的表格式排行，和账页同一套语言；环形图会让画面回到「App 仪表盘」。
- **设置不做卡片**：用清单式行，导出动作明确写出结果（CSV / JSON / 恢复）。
- **封面保留大留白**：作为一份「文件」的扉页，留白是版式的一部分；如果实现，首屏仍会把「开始记账」固定在拇指区。

## 底部操作 tab

- 54px 高，三等分；顶部 1px 墨线，项间 1px 分隔线。
- 每项：17px 线性图标 + 10px 等宽序号 + 12px 名称，水平居中。
- 选中：主色 8% 浅底 + 2px 主色顶线；图标和序号同步主色，名称回到墨色。
- 整块 tab 可点，序号不是独立按钮；不做中间凸起 FAB，因为记账页已有一个整宽的「记下这笔」。

## 配色变体

同一版式做了三套配色，切换 `?theme=pine|cobalt|clay`：

- **A 松墨**：米纸 `#F1EEE0` + 松绿 `#2F5A43` + 麦黄/砖红；安静但有颜色。
- **B 钴蓝**：雾纸 `#EEF1F4` + 钴蓝 `#2B4E78` + 陶橙；像银行月结单。
- **C 朱砂**：陶纸 `#F7EADF` + 朱砂 `#B2472F` + 橄榄；最暖、最有存在感。

细节见 [`colors/README.md`](colors/README.md)。

## 评审与修正

独立子 Agent 逐屏评审（未改文件），给 **7.5 / 10（方向 9，落地 6）**。主要意见与修正：

1. **裁切/网格**：报告内容 868px 超出 844，nav 被切；数据页脚 x=0；结论红竖线贴屏幕边。→ 折线替换周柱后内容缩短；`.note` 放回 18px 网格；`.foot` 改为只设置上下 padding；ledger 去掉一天的数据，避免汇总压到 nav。
2. **对比度**：11px 标签 #7E7767 只有 4.04:1，明细备注 12px 同色。→ `--ink-3` 改为 `#6B6254`；明细备注升到 12.5px 并改用 `#555044`；行线加深。
3. **明细层级**：三种元信息挤在一个灰阶、10.31 时间乱序、小计没有标签。→ 时间重排（21:50 / 10:37 / 08:23），小计加「小计」前缀并右缩，行高 37→42，点线减弱。
4. **数据表达**：周柱 5 桶不等长、41% 重复 3 次。→ 改为 31 点折线；KPI 第三格改为「笔均 ¥131.71」。
5. **印章与入口**：空红方块占掉设置入口。→ 顶栏改齿轮，封面用 26px「账」印章；数据页右上改关闭。
6. **记账触达**：日期/备注/付款只有 21px 高。→ 改成 44px 三格字段，带上「日期 / 备注 / 付款」标签；医疗图标由圆圈加号改为药丸。
7. **筛选**：明细只列 6 个分类。→ 增加「更多 +」，保留全部筛选入口。

未再评分；未做空态/状态栏/手势区（见「未做」）。
