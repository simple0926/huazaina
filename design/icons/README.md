# 花在哪 · App Icon 三个方向

## 产品事实

- 用户：只在手机上记账的个人；关心「钱花在哪、从哪来」，不想把数据交给云端。
- 任务：在 390×844 的桌面上，62px 的图标要一眼认出是账，第二眼认出是「我自己的」。
- 限制：Android 10+；松墨纸色系统（纸 `#F1EEE0`、墨 `#1A2018`、松绿 `#2F5A43`）；无渐变、无 3D、无外部图片。
- 桌面是 squircle 图标；系统图标为中性占位，不出现真实品牌。

## 北极星

**把一本纸账缩成一枚记号：一眼知道是账，第二眼知道只属于你。**

删除清单：不要钱包、硬币、柱状图、饼图、信用卡、字母缩写、多个符号、投影和渐变。每个图标只留一个主角、一个动作。

## 三个方向

### A / 账页 THE PAGE

四条账线 + 一枚绿印。最接近现在这版图标，像从月结单上裁下的一角。

- 主角：右下角绿印；动作：翻开一页。
- 优点：48px 仍读得出「一页账」，最稳。
- 代价：最像「笔记」，品牌惊喜最少。

### B / 收支 THE BALANCE

一张带墨框的纸，¥ 的下半截是松绿。上半是支出，下半是收入。

- 主角：¥；动作：一进一出。
- 优点：第一眼是钱，最贴「收支」这个新功能；像一张单据。
- 代价：纸色在纸色桌面上最安静，存在感弱于 A/C。

### C / 私章 THE SEAL

整块松绿、一圈纸边、一个「账」字。不是账本，是给账本盖的章。

- 主角：「账」字；动作：盖章。
- 优点：桌面上最认得出；48px 下字会变密，但绿块和纸边还在；圆形启动器也最稳。
- 代价：最像「品牌印记」，不那么像工具。

## 桌面

同一张桌面、同一组系统图标，只换左上角「花在哪」。时钟 10:31，纸色横线壁纸，松墨 dock。

- 桌面 390×844；图标 62px；系统图标为中性占位。
- 大图 `shots/home-a.png`、`home-b.png`、`home-c.png`。
- 对比板 `shots/board.png`；尺寸表 `shots/sheet.png`。

## 尺寸与边界

- 1024 主图，圆角 224；48 / 72 / 96 检查；桌面 62。
- 按 squircle 展示；若你的启动器是圆形，C 最稳，A 的印章和 B 的框角需要再往安全圆收一点，选定后我出修正版。
- SVG 中的「¥ / 账」调用宋体；交付的 PNG 已栅格化。正式做 Android 自适应图标时，会把字转成 path，并拆 foreground / background 两层。

## 选型建议

- 想要**最稳、最连续**：A。
- 想要**把收入/支出讲清楚**：B。
- 想要**桌面上最认得出、最像这套纸账**：**C（我的推荐）**。
