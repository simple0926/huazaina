# 花在哪 · logo concepts 01

三版方向，停在概念检查点，等选定后再做完整套件。  
依据 `logo-design` skill 的流程：先黑白、先 16 px、先定形，再谈配色与落地。

## 简报（已按现有产品补全）

- 产品：花在哪，个人收支账本；本地存储、不上传、Android。
- 用户：只给自己看；在意数据所有权，不要记账 App 的“理财感”。
- 气质：安静、可信、私密、纸感、克制、微暖。
- 要求：中文名「花在哪」；符号 + 横版字标；16 px 可用；单色可用；最终配松墨绿 / 纸色 / 墨色。
- 避开：硬币、钱包、存钱罐、上升箭头、¥/$、放大镜、蓝色渐变、通用定位针。

## 三版

### A / 一页 THE PAGE

三条账线 + 一枚私印，把月结单缩成一张纸。  
最稳，延续现在的 App 图标；代价是容易像“文档”，16 px 时账线会糊。

### B / 私章 THE SEAL

花字圆印，把名字盖成自己的章。  
最像品牌，也最直接说“数据只在我手里”；代价是花字缩小会糊，印章语汇偏传统。

### C / 问号 THE QUESTION（推荐）

账线折成问号，句点是方印。  
名字本身就是问题；16 px 仍是一个问号，且没有记账 App 的老套符号。  
代价是单独一个问号会像“帮助”，所以正式使用时始终和字标一起出现。

## 状态与下一步

- 字标目前是 **Songti 宋体示意**，不是最终转曲；B 的「花」也是字体，不是手绘。
- A/B 是“深色底 + 纸色细节”的 tile；正式套件会补透明孔 / 反白 / 单色版本。
- C 是描边构成；正式套件会展开为实心轮廓。
- 选定方向后再做：字标转曲、松墨绿/纸色、反白与单色、横竖锁合、Android 自适应图标 / favicon、尺寸与使用规范、完整导出包。
