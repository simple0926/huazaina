# 花在哪 · 3 logo directions

先定核心，再出三版；三版不是三种风格，而是同一核心的三个面向。

## 核心

> 把「钱花在哪」变成一本只给自己看的清楚账。

- 不是理财/预算教练，不评判消费，不制造焦虑。
- 用户的问题：现有记账 App 把“分析/导出”放在付费墙后，数据不在自己手里；记了，却看不清钱去了哪。
- 核心任务：**记一笔 → 看明白 → 拿走**（CSV/JSON）。
- 情绪：安静、清楚、可控、私密。
- 品牌的“主角”是 **“在哪”这个问号**；功能的主角是 **金额 + 记一笔**。

## 删除清单

硬币、钱包、存钱罐、上升箭头、¥/$、放大镜、通用定位针、通用花朵、通用红印章、渐变、第二强调色、英文副标。

## 三版

| | 面向 | 一句话 | 代价 |
| --- | --- | --- | --- |
| 01 问号 | WHERE | 名字本身就是问题；账线折成问号，方点是章 | 单独像“帮助”，需配字标 |
| 02 账页 | PAGE | 三行账线，一枚私印；月结单缩成一页 | 缩小像文档，16 px 账线会糊 |
| 03 私章 | OWNER | 花字圆印；数据只在我手里 | 花字缩小会糊，印章语汇偏传统 |

## 推荐

**01 问号。** 它最直接回答「花在哪」，16 px 仍成立；02 最稳，延续现在的图标；03 最像品牌，适合做印章/包装，但不适合单独做 16 px 图标。
