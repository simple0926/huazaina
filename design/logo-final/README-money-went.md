# 钱去哪了 / the missing dot

按「钱去哪了」设计，不再另开三个方向：只把这一句话做成一个标记。

## 一句话

**点，就是钱。**  
问号是问题；点离开原来的位置，留下三个小点——钱去哪了。报告负责回答，logo 负责把问题一直留在桌面上。

## 距离

试了三档：

- **01 太近**：像没走，还是原来的问号。
- **02 刚好**：还认得出问号，也看得出点已经走了；留三个小点当路。
- **03 太直**：像漏了/掉下去，方向不明。

选 **02**。
